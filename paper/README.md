# paper/

Manuscripts about agrinutri. Not part of the R package (excluded by `.Rbuildignore`).

| Path | Content |
|---|---|
| `sat/` | Smart Agricultural Technology article (soil-map uncertainty of the regulatory N dose, CERZOO case study): manuscript, analysis scripts 00 to 07, figures, `notes/` (writing review, deep-research notes and report) |
| `softwarex/` | SoftwareX software article (agrinutri architecture, functionalities, verification, examples), its figures and the SoftwareX template |
| `data/` | ISTAT yield benchmark used by the SAT article (`fetch_istat_yields.R`) |
| `references.bib`, `references_review.bib` | shared bibliography of both manuscripts |
| `reference-agrinutri.docx`, `make_refdoc.py` | Word house style used by the pandoc renders |
| `_archive/` | superseded drafts and figure scripts (January to July 2026), reference only |
